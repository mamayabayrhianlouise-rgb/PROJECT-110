PROJECT DESCRIPTION

Quotezy is a Random Quote Generator website that displays inspirational
and meaningful quotes. The project includes a portfolio homepage and a
main application page where users can generate and copy random quotes.

TECHNOLOGIES USED

-   HTML
-   CSS
-   JavaScript
-   DummyJSON Quotes API

PROJECT FILES

-   index.html - Portfolio homepage
-   app.html - Main Random Quote Generator application
-   styles.css - Website styling and responsive layout
-   script.js - JavaScript functionality and API integration
-   images/ - Images and other visual assets
-   README.txt - Project information and instructions

API USED

API Name: DummyJSON Quotes API

API Documentation: https://dummyjson.com/docs/quotes

The DummyJSON Quotes API is used to retrieve quote data for the Quotezy
application.

HOW TO RUN THE APP

No special installation is required.

1.  Download or clone the Quotezy repository from GitHub.
2.  Make sure all project files and the images folder are in the correct
    folder structure.
3.  Open the project folder in VS Code or another code editor.
4.  Open index.html in a web browser.
5.  Click “Try the App” to open app.html.
6.  Use the quote generator button to retrieve a random quote.
7.  The application will request quote data from the DummyJSON Quotes
    API.

IMPORTANT: An internet connection is required for the application to
retrieve quotes from the API.
