OUR PROJECT

The goal is simple.

Project chosen: Random Quote Generator.

Main goal: Instead of searching through many websites, users click one button and receive a brand new quote from a public API.

We built it with HTML for structure and CSS for design and JavaScript to connect the API. We wanted the app to feel clean and enjoyable.

— ABOUT QUOTEZY —

A small quote
can change
your perspective.

Quotezy is a simple random quote generator made to help you discover meaningful thoughts quickly and easily.

HOW IT WORKS —

Three simple steps.

01

Click

Press the Get a Quote button to request a new quote.

02

Fetch

JavaScript sends a request to the public quote API.

03

Discover

The quote and author appear right on the page.

— THE API —

Powered by a public quote API.

API used: DummyJSON Quotes
Documentation: dummyjson.com/docs/quotes
